# Лендинг «Модуль» — блок-контейнеры, КПП, модульные здания

Одна статичная страница без сборки и зависимостей. Форм нет: посетитель звонит,
пишет на почту или в мессенджер — персональные данные сайт не собирает.

## Посмотреть локально

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765

## Что где

- `index.html` — вся страница. Порядок блоков повторяет главную delfacom.ru.
- `css/style.css` — стили, цвета и шрифты в `:root`.
- `js/main.js` — **контакты (`CONTACTS`)**, окно «Как вам удобнее связаться?»,
  галереи, вкладки, меню, цели Метрики (`METRIKA_ID`).
- `fonts/` — Manrope, локальная копия.
- `img/` — фото (временные, см. `img/SOURCES.md`).
- `tools/build-images.py` — готовит фото из `img/src/`: убирает логотип референса,
  ужимает, сохраняет WebP. Уже готовые файлы пропускает.

## Сменить контакты

1. `CONTACTS` в начале `js/main.js` — подставляется во все кнопки и ссылки.
2. Те же значения в `index.html` (запасной вариант без JS и для поисковиков, плюс
   блок `application/ld+json`) — поиск-замена старого номера/почты.

## Кнопки «Рассчитать …»

Любой элемент с атрибутом `data-ask` открывает окно «Как вам удобнее связаться?»:
звонок, WhatsApp, Telegram, MAX, почта. Значение атрибута на сайте не показывается.

## После правок CSS или JS

Увеличьте номер версии в `index.html` (`style.css?v=2`, `main.js?v=2`), иначе браузеры
посетителей могут ещё час показывать старый файл из кэша.

## Выкладка

На хостинг идут: `index.html`, `.htaccess`, `css/`, `js/`, `fonts/`, `img/*.webp`.
Не заливать: `img/src/`, `tools/`, `.claude/`, `README.md`, `img/SOURCES.md`.

## Перед запуском рекламы

- Заменить фото на свои (имена файлов те же).
- Подтвердить факты: гарантия, работа с НДС, география доставки, свой транспорт.
- Вписать ID Яндекс.Метрики и код счётчика.
- Свою почту «Модуля» вместо почты СКБ «Источник», если будет.
